# Sistema BBDD Farmacia

Proyecto de base de datos desarrollado como parte de formación en Ingeniería en Informática.

## Descripción
Este sistema modela la gestión de una farmacia, incluyendo:
- Medicamentos
- Stock
- Relación de datos
- Scripts SQL para creación y carga de datos

## Estructura del proyecto
- `/Medicina/Modelo`: Modelos de datos (CDM, LDM, PDM)
- `/Medicina/SQL`: Scripts SQL
- `/Farmacia`: Archivos del sistema

## Tecnologías utilizadas
- SQL
- Modelado de datos
- Bases de datos relacionales

## Objetivo
Diseñar e implementar una base de datos funcional para la gestión de una farmacia.
